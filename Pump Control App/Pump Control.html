Calibrate the colour sensor

    
  

  

    
Each standard has a known concentration, C = drops × 0.05 mL / 350 mL. The sensor gives its absorbance, A = −log10(f / f0), with f0 from clear water. The calibration curve is the straight line through A against C. Pumps were stopped when this opened.

      •

      • 
          
    • Box closed, no shadows, nothing moved, lighting unchanged for the whole calibration.
      • 
          
    • Standards use drops of the same dyed reservoir solution the pump uses (1 drop = 0.05 mL), never raw dye.
